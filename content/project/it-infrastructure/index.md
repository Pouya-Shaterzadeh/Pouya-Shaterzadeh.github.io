- 🌍 Multi-region Rocket.Chat with Federation
- 📞 Asterisk PBX VoIP stack
- 🔒 Traefik with Let's Encrypt SSL
- 🐳 Docker Compose orchestration
- 📊 Prometheus metrics & monitoring
