# PROJECT HIERARCHY

Not every project needs to have the same visual size.

Use project importance to determine layout prominence.

For example:

### TIER 1 — MAJOR PROJECTS

These should receive large, immersive layouts:

- VeriShelf
- Style Finder AI
- DroneX / autonomous drone work
- Sky Warriors
- major infrastructure work

These can use:

- large horizontal feature blocks
- large visual areas
- architectural diagrams
- prominent typography

### TIER 2 — STRONG PROJECTS

These should receive medium-sized editorial cards.

They should still have:

- meaningful visuals

But they do not need to dominate the screen as much as the major projects.

### TIER 3 — SMALLER PROJECTS

Academic projects, experiments, utilities, and smaller implementations should STILL be included.

However, they can use more compact treatments.

└───────────────────────────────┘

These projects should still feel like part of the same portfolio rather than being hidden in a separate section.
